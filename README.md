# DS Nails 💅

Projeto desenvolvido para a disciplina de **Interface Homem-Computador (IHC)**, com o objetivo de criar um site para um salão de beleza especializado em serviços de manicure e pedicure.

O site DS Nails oferece uma interface intuitiva e agradável, permitindo que os clientes conheçam os serviços disponíveis e realizem uma simulação de agendamento online.

## 🌐 Acesse o projeto

**Site publicado:** https://dsnailss.netlify.app/

O projeto está hospedado na plataforma [Netlify](https://www.netlify.com/).

## ✨ Funcionalidades

- Página inicial com apresentação do salão.
- Exibição dos serviços oferecidos.
- Descrição dos serviços, duração e valores.
- Sistema de agendamento online.
- Seleção de serviços, datas e horários disponíveis.
- Formulário para preenchimento dos dados do cliente.
- Validação dos campos obrigatórios.
- Tela de resumo e confirmação do agendamento.
- Opção para iniciar um novo agendamento.
- Interface responsiva, adaptada para diferentes tamanhos de tela.
- Recursos de acessibilidade e navegação intuitiva.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, identidade visual e responsividade.
- **JavaScript:** funcionalidades e interatividade do sistema de agendamento.
- **Bootstrap 5.3.3:** componentes e layout responsivo.
- **Bootstrap Icons 1.11.3:** utilização de ícones.
- **Google Fonts:** fontes Poppins e Playfair Display.
- **Netlify:** hospedagem e publicação do projeto.

## 💻 Como executar o projeto

Para executar o projeto localmente:

1. Faça o download dos arquivos ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Para facilitar o desenvolvimento, também é possível utilizar a extensão Live Server no Visual Studio Code.

Não é necessário instalar dependências adicionais.

## 📌 Observação

O sistema de agendamento possui caráter demonstrativo. As informações preenchidas são validadas e apresentadas na tela de confirmação, mas não são armazenadas em banco de dados nem enviadas para um servidor.
